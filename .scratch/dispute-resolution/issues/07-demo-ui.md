# 07: Demo UI

**What to build:** The web interface a presenter uses on Demo Day. They pick a prepared mock Dispute, run it with one click, and watch the Communication Log fill in live as agents request evidence, file Submissions and rule. When the Case is ruled they see a Ruling card and the rider and driver Outcome views side by side. They can open any Case and see its Evidence Items, both Submissions, the Ruling and the log together. Everything simulated is labelled as simulated.

**Blocked by:** 02

**Status:** ready-for-agent

**Tier:** 0 · **Owner:** Braedon

- [x] A list of prepared mock Disputes can be browsed and one run with a single click
- [x] The Communication Log updates live during a run (a run starts in the background; the console polls and reveals each event at the chosen replay speed)
- [x] The Ruling card shows outcome, amount, Confidence with its components, reasoning, per-argument assessment, and cited evidence and clauses
- [x] Cited Evidence Items and Policy Clauses can be opened from the Ruling
- [x] Rider and driver Outcome views are shown side by side (checked in a headless Chrome screenshot)
- [x] A recommended action is visibly different from an executed one (recommended is a dashed blue card, pending review dashed amber, executed solid green; the system never produces `executed`, so that style is CSS only)
- [x] Mock data, mock policy and simulated financial actions are labelled on screen
- [x] The UI can be built against a recorded log stream, without the orchestrator running (`/?recorded=1`, streams in `src/api/static/recorded/`, regenerated by `scripts/record_cases.py`)

**How to run it:** `uv run uvicorn src.api.demo:app`, then open `/`. Add `?recorded=1` for the recorded streams, `&run=DISP-003` to start a dispute straight away, and `&tab=ruling` to open a tab. The console reuses the rider app's own stylesheets (`prototypes/shared/waypoint.css` and friends), so it looks like Waypoint. Looks were checked in headless Chrome screenshots; tab switching and ID navigation were not clicked through in a real browser.
