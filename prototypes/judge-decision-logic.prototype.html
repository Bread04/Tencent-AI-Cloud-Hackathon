How the Judge's ruling becomes a decision

The question this answers: once the Judge has assessed a case, do our rules for Confidence (lowest component wins), the History step, and the review triggers send each case to the place we would want, finalised automatically or sent to a human reviewer, especially in the awkward cases?

This covers only the fixed rules in code. It does not run a language model, so it says nothing about how well the Judge's prompt reads a case. Everything here uses a No-Show Charge case as the example. Numbers are the starting values from the architecture doc.
